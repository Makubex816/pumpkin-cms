# Ice Rink Rentals Research

This folder contains research templates for the `ice-rink-rentals` tenant.

Primary service:

- Portable Ice Rink Rentals

Use this site folder for state research and page recommendations that are specific to portable ice rink buyers. Do not copy Roller recommendations directly unless the geography, buyer intent, fulfillment logic, and content value are independently justified.

Ice page recommendations should consider:

- holiday activations
- winter events
- municipal events
- shopping center activations
- school and campus events
- synthetic ice logistics
- surface, power, access, and weather constraints
- confirmed partner or provider coverage

Research-only pages should not be recommended for publishing until fulfillment status, public disclosure, and routing path are clear.

Validate from the repo root:

```powershell
node research/scripts/validate-research.mjs
```
