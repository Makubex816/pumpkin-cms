# Roller Rink Rentals Research

This folder contains research templates for the `roller-rink-rentals` tenant.

Primary service:

- Portable Roller Rink Rentals

Use this site folder for state research and page recommendations that are specific to portable roller rink buyers. Do not copy Ice recommendations directly unless the geography, buyer intent, fulfillment logic, and content value are independently justified.

Roller page recommendations should consider:

- school events
- community events
- corporate activations
- indoor and outdoor surface requirements
- skate inventory needs
- staffing and barriers
- warm-weather seasonality
- confirmed partner or provider coverage

Research-only pages should not be recommended for publishing until fulfillment status, public disclosure, and routing path are clear.

Validate from the repo root:

```powershell
node research/scripts/validate-research.mjs
```
