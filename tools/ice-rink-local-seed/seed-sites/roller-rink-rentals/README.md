# Roller Rink Rentals Local Proof Seed

This folder contains safe seed data for the `roller-rink-rentals` local proof tenant.

It is intentionally local-proof content:

- No real API key hash is committed.
- No connection strings or secrets are committed.
- Page content is realistic enough to test the Roller Rink Rentals flow, but should be reviewed before production.
- Canonical URLs use `https://rollerrinkrentals.com`.

Use `SITE_KEY=roller-rink-rentals` with a local-only `ROLLER_RINK_RENTALS_API_HASH` value to seed this tenant.
