# Preflight Scope

## Approved

- Planning and documentation only.
- Use Phase 2F-12C and Phase 2F-12D safe evidence.
- Define the future Cosmos target plan.
- Define owner-confirmation worksheet and gates.
- Define metadata endpoint readiness and provider resolver integration.
- Create root report and next approval prompt.

## Not Approved

- Cosmos account/database/container provisioning.
- Azure resource creation or mutation.
- Azure CLI commands.
- Database export or import.
- CMS/API calls or mutations.
- CMS writes.
- Protected config reads.
- Secret export.
- Deployment.
- Search Console/indexing.
- Live-page publication.
