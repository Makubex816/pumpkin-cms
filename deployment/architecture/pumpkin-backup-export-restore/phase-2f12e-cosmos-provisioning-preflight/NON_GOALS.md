# Non-Goals

Phase 2F-12E does not:

- create a Cosmos account;
- create a Cosmos database;
- create Cosmos containers;
- assign RBAC roles;
- configure managed identity;
- change app settings;
- wire CMS runtime;
- seed or migrate CMS data;
- export or import database records;
- call CMS/API endpoints;
- run Azure commands;
- read protected config;
- deploy code;
- publish live pages.

All of those actions require separate future approvals.
