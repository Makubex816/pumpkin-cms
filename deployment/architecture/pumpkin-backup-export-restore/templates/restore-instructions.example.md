# Restore Instructions Example

## Required Order

1. Validate manifest.
2. Verify checksums.
3. Generate restore plan.
4. Restore to local or sandbox only.
5. Run readback validation.
6. Request separate approval before any production restore.

## Escrow

This standard backup example does not include escrow. If escrow exists in a recovery backup, escrow restore requires a separate approval and private restore workspace.

## Hard Stop

Do not restore to production from this example.
