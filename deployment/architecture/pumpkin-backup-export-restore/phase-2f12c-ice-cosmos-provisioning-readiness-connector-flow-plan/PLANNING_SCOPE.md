# Planning Scope

## Approved

- Update the Backup Center roadmap.
- Create a planning package for Ice Cosmos provisioning/readiness and connector execution flow.
- Use Phase 2F-12A and 2F-12B evidence.
- Define approval gates and sequencing.
- Keep local-dev and live runtime profiles separate.
- Create docs and reports only.

## Not Approved

- Implementation.
- Cosmos provisioning.
- Azure mutation.
- Database export or import.
- CMS writes.
- CMS/API calls or mutations.
- Protected config reads.
- Secret export.
- Deployment.
- Search Console or indexing actions.
- Live-page publication.

## Worktree Note

Phase 2F-12B planning files are present in the worktree and remain unstaged. Phase 2F-12C adds a separate package and updates the top-level Backup Center roadmap.
