## Purpose

Define the exact operator-ready scope for the first real Pumpkin Backup Center proof target: IceSkatingRinkRentals.com.

The future approved execution should create a standard backup bundle that captures enough website, CMS, database, media, static evidence, and redacted configuration inventory to validate recovery readiness without including secrets.

- CMS tenant/site/content records.
