# Non-Goals

Phase 2F-2 does not:

- implement backup code;
- create a `package.json` for the future implementation;
- create source modules;
- create backup folders or zip files;
- export database data;
- export CMS records;
- export media;
- export static artifacts;
- export or read secrets;
- create encrypted escrow payloads;
- decrypt escrow payloads;
- restore data;
- call CMS/API endpoints;
- use POST, PUT, PATCH, or DELETE requests;
- modify Azure, Cloudflare, DNS, Function App settings, deployment, email, Microsoft 365, Search Console, or indexing;
- read protected config;
- stage generated artifacts;
- publish live pages.

Implementation starts only after a later Phase 2F-3 approval.
