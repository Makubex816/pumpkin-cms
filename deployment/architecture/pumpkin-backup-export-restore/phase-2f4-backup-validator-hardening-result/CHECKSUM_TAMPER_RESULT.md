# Checksum Tamper Result

Checksum validation now detects:

- changed file contents;
- missing checksum entries;
- checksum entries for missing files;
- malformed checksum lines;
- duplicate checksum paths;
- unsafe checksum paths;
- checksum file self-inclusion;
- volatile validation report entries.

`checksums.sha256` remains excluded from its own coverage, and validation reports remain excluded because they are regenerated by validation.
