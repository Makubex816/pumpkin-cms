# Dry-Run Scope

Approved scope:

- use the provisioned Cosmos future-target metadata from safe fixtures
- use the validated Ice standard backup baseline under ignored `.tmp`
- map tenant, site, page, route, form, SEO, media metadata, theme, and import-run provenance documents
- validate `/tenantKey` tenant isolation
- write output only under ignored `.tmp`
- update Backup Center local tooling and docs

Explicitly out of scope:

- live Cosmos writes
- CMS writes or runtime switch
- database export or import
- media/blob download
- protected config reads
- Azure mutation or key/listKeys calls
- deployment, Search Console/indexing, or live-page publication
- staging generated seed package artifacts
