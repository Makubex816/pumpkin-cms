# Known Limitations

The Phase 2F-13 generator is a local CLI product workflow, not a deployed Backup Center service.

Remaining limitations:

- no restore execution;
- no CMS runtime cutover;
- no Admin UI job orchestration;
- no Electron operator app;
- no production escrow payload in standard backups;
- no durable artifact repository outside owner-approved handling;
- no automated retention enforcement outside local cleanup guidance;
- no Outbound Link Manager execution;
- no deployment or live publication step.

The optional ZIP package is a local convenience artifact. It should be retained only through a separate owner-approved retention process.
