# Standard Backup Format

## Folder Bundle

```text
<bundle>/
  manifest.json
  checksums.sha256
  BACKUP_SUMMARY.md
  VALIDATION_RESULT.md
  validation-result.json
  RESTORE_INSTRUCTIONS.md
  database/
    DATABASE_EXPORT_NOT_INCLUDED.md
    database-export-plan.json
  cms-content/
    tenants.json
    sites.json
    pages.json
    routes.json
    forms.json
    seo.json
    redirects.json
    theme.json
  media/
    media-assets.json
    MEDIA_BLOBS_NOT_INCLUDED.md
  static/
    static-output-manifest.json
    STATIC_OUTPUT_NOT_INCLUDED.md
  config-inventory/
    env-inventory.redacted.json
    CONFIG_VALUES_REDACTED.md
  escrow/
    ESCROW_NOT_INCLUDED.md
```

## Manifest Contract

`manifest.json` must declare:

- `manifestVersion: "0.2.0"`
- `bundleContractVersion: "0.2.0"`
- `validatorContractVersion: "0.2.0"`
- `backupMode: "standard"`
- `bundleFormat: "folder"`
- `includesEscrow: false`
- `checksumAlgorithm: "sha256"`
- valid `tenant` or `platform` scope fields
- `contentFileCount` matching `files.length`
- safe bundle-relative manifest file paths

The manifest file list covers generated content files only. It excludes:

- `manifest.json`
- `checksums.sha256`
- `VALIDATION_RESULT.md`
- `validation-result.json`

## Checksum Policy

`checksums.sha256` covers generated bundle files except:

- `checksums.sha256`
- `VALIDATION_RESULT.md`
- `validation-result.json`

The checksum file must not include itself. Validation report files are volatile and regenerated by the validator.

## Standard Secret Policy

Standard backups exclude secrets. They must include `escrow/ESCROW_NOT_INCLUDED.md` and must not include encrypted escrow payloads, protected config files, API keys, JWTs, auth headers, cookies, tokens, connection strings, storage keys, or private keys.

`config-inventory/env-inventory.redacted.json` may contain variable names and presence markers only. Values must be redacted markers such as `REDACTED` or `NOT_COLLECTED`.

## Output Policy

Generated test bundles and restore-plan dry-run outputs are local folders under `.tmp/`. Production backup zips, real database exports/imports, real CMS/API exports/restores, media blob downloads/restores, real static output/restores, encrypted escrow payloads, real restore output, and external system mutations are outside this phase.
