# Known Limitations

## Still Not Production-Ready

- Runtime profiles are local/fixture-backed.
- Live-readonly profiles do not make live calls yet.
- The CMS runtime is not switched to Cosmos.
- Ice tenant data has not been seeded or migrated into Cosmos.
- Live database export remains blocked.
- Production restore proof is not complete.
- Admin UI integration is not implemented.
- Electron integration is not implemented.
- Outbound Link Manager is not implemented.

## Required Future Work

- Data seed and migration preflight
- Runtime read-only verification
- Backup proof after data is available in the runtime provider
- Production runtime switch preflight
- Deployment and live-page publication approvals, later and separately
