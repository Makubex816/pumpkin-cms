# Known Limitations

- The endpoint is a foundation route for the Ice provisioned future-target profile, not a full runtime provider switch.
- The endpoint does not prove the CMS runtime is using Cosmos.
- The endpoint does not expose runtime configuration values.
- No managed identity/RBAC wiring was changed.
- No Ice data has been seeded or migrated.
- Live database connector execution remains blocked.
- Ice is not fully backupable today.
- Live pages remain hard-stopped.
