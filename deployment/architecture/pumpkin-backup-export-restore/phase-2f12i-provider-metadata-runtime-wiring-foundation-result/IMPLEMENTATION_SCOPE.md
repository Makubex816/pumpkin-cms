# Implementation Scope

## Implemented

- `GET /api/admin/provider-metadata`
- Static non-secret Ice provider metadata service
- Endpoint authorization guard
- Backup Center runtime profile bridge
- CLI runtime-profile summary command
- Provider resolver tests for endpoint-safe response shape
- Docs and result package

## Not Implemented

- CMS runtime switch to Cosmos
- Runtime configuration value wiring
- Managed identity/RBAC mutation
- Data seed or migration
- Live database connector execution
- Database export/import
- Cosmos document export
- Deployment
