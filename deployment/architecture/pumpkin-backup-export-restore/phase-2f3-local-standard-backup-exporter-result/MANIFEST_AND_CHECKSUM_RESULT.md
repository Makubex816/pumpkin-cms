# Manifest And Checksum Result

## Manifest

The prototype writes `manifest.json` with:

- `manifestVersion`
- `backupMode: standard`
- scope and tenant key
- created timestamp
- `createdBy: local-prototype`
- `source: fake-fixture`
- `bundleFormat: folder`
- `includesEscrow: false`
- file list
- checksum algorithm
- schema references
- warnings
- exclusions

## Checksums

The prototype writes `checksums.sha256` using Node crypto SHA-256.

Checksum policy excludes:

- `checksums.sha256`
- `VALIDATION_RESULT.md`
- `validation-result.json`

Validation outputs are regenerated by the validator and intentionally treated as volatile reports.
