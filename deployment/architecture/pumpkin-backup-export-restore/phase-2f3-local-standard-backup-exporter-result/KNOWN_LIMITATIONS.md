# Known Limitations

- Fake adapters only.
- Folder bundle only; no zip creation.
- No real CMS/API read adapter.
- No database export adapter.
- No media blob copy adapter.
- No static output export adapter.
- No encrypted escrow payload support.
- No restore validation beyond bundle validation behavior.
- No background job queue.
- No API endpoints.
- No Admin UI.
- Validator is a prototype and needs Phase 2F-4 hardening.
