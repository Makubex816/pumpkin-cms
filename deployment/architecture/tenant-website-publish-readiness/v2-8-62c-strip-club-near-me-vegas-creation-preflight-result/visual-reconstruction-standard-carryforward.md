# Visual Reconstruction Standard Carryforward

The static package remains the visual source of truth. V2.8.62B proved 4 representative static routes over mobile and desktop and normalized all 43 source Pages. That proof does not by itself establish that the Pumpkin Page/Theme renderer can reproduce the site.

Current parity accounting:

- source routes normalized: 43/43;
- Page-model slug candidates unique: 43/43;
- nested source routes needing explicit runtime mapping: 29;
- club/detail subsets preserved: 10/10;
- guide/article subsets preserved: 19/19;
- source redirects requiring preserved redirect/target behavior: 3;
- actual missing anchor targets requiring repair: 2;
- validator compatibility aliases excluded from source count: 1;
- Pumpkin-renderer full-route proof: pending.

Before any later live creation approval, the 62CR adapter must:

- map nested source paths to unique Page slugs without changing public route intent;
- carry source title, H1, metadata, semantic sections, page-specific CSS, images, links, forms, and structured content;
- include source-backed item and article details rather than a generic hero/CTA fallback;
- preserve all intentional Airstrip links and all three source redirects;
- repair both missing anchor targets;
- preserve all 65 form-instance contracts and every mapped control action;
- preserve catalog/detail and blog/article depth, links, and media;
- reimplement required interactions without executing uploaded JavaScript;
- render all 43 routes locally with no generic fallback marker; and
- pass representative mobile/tablet/desktop visual, image, overflow, request-method, and route-link checks.

The durable compiled JSON remains evidence but requires fidelity-contract recompilation before it can be a live-import input. The verified source ZIP remains authoritative. Owner visual and functional acceptance remains separate from tenant creation, deployment, and CMS publication.
