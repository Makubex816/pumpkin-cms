# Production Gates Still Closed

The following gates are not approved by V2.8.3:

- staging deployment
- production deployment
- DNS mutation
- Search Console/indexing
- live-page publication
- CMS runtime switch
- CMS content writes
- MediaAsset writes
- provider data writes
- production database migration
- Azure infrastructure mutation
- RBAC assignment
- keys/listKeys
- connection-string generation
- SAS generation
- external crawling or live outbound URL checks

Any future transition beyond local signoff requires a new explicit approval.
