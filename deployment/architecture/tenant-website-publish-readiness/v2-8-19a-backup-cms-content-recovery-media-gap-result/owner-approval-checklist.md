# Owner Approval Checklist

Required before source integration or staging:

- approve using the backup CMS pages as the content source of truth
- approve restored route set: `/`, `/service-areas`, `/contact`
- approve obsolete 404 behavior for `/ice-rink-rentals` and `/events-holiday-activations`
- approve recovered page titles, H1s, sections, CTAs, and form behavior
- approve all recovered image slots
- approve image license status and usage rights
- approve alt text for each image
- approve whether the 3 metadata-only extra media records are ignored, recovered, or replaced
- approve binary recovery method
- approve isolated-staging-only validation before production
- approve production-bound deployment separately only after isolated staging signoff

Owner approval must be visual/content specific, not only technical route availability.
