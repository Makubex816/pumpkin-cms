# Deferred Gates Summary

The following gates remain deferred after V2.8.32C:

- Azure resource creation.
- App Service deployment.
- Azure app setting list/show/set.
- Protected provider config binding.
- Key Vault secret query.
- Deployment token use/list/print/export/reset.
- Production or isolated contact POST.
- Production API writes.
- Admin live readback.
- Static contact production binding.
- DNS/custom-domain mutation.
- Search Console/indexing.
- Inbox/provider login.
- Backup/export proof of the eventual persisted contact record.

V2.8.32D should address only App Service provisioning/deployment and initial health, unless the user explicitly approves a broader protected binding/readback phase.
