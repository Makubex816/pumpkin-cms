# Owner Decision Checklist

Owner decisions required before recovery implementation:

- confirm whether to recover an exact old image-heavy site or rebuild a new image-rich version
- provide or approve the image source package
- approve image usage rights and alt text
- approve route list
- approve homepage sections, order, copy, images, CTAs, and mobile behavior
- approve service-area page sections, copy, images, CTAs, and claims
- approve contact/quote path fields, success state, email behavior, and copy
- approve header/nav and footer content
- approve SEO title, description, canonical, Open Graph, and Twitter image values
- approve isolated staging target review process
- approve production rollback plan before any production-bound deploy

Owner content approval must be visual and route-specific, not just a technical route availability signoff.
