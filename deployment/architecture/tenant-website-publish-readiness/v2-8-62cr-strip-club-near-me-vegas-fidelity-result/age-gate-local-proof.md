# Age Gate Local Proof

The owner-directed local-only 21+ acknowledgement is implemented in the trusted adapter. It uses only `sessionStorage` key `scnmv_age_ack`; it does not use localStorage, cookies, network requests, or personal data.

Mobile 375x812 and desktop 1366x900 screenshots proved the dialog, accessible role, modal state, copy, and both controls. Decline kept the preview closed. Accept hid the dialog and set the session-only acknowledgement. LocalStorage remained empty.
