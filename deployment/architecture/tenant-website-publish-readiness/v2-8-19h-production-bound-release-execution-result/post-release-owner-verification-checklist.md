# Post-Release Owner Verification Checklist

Next phase: owner business/content verification on production domains.

Owner should verify:

- Homepage loads on apex and `www`.
- Service areas page loads on apex and `www`.
- Contact page loads on apex and `www`.
- Header/nav/footer links work visually on desktop and mobile.
- Public email `contact@iceskatingrinkrentals.com` is correct.
- Contact page mailto behavior opens the expected email client.
- Azure media visuals match owner expectations.
- No outdated staging-only language is visible.
- Mobile layout is acceptable on owner-reviewed devices.
- Any business copy, availability, legal, or claim corrections are listed before indexing or contact-form submission approval.

Still not approved in this package:

- Contact form POST.
- Search Console/indexing submission.
- Sitemap submission.
- URL Inspection API.
- Google Indexing API.
- DNS or custom-domain mutation.
