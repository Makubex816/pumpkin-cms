# Trace Logging Result

Trace logs include:

- request ID
- action ID
- correlation ID
- tenant key
- site key
- provider mode
- action
- entity IDs
- outbound link ID
- instance ID
- policy ID
- scan-run ID
- bulk-action ID
- audit IDs
- rollback-plan ID
- before state hash
- after state hash
- affected page IDs
- affected instance IDs
- actor identity
- actor role
- outcome

Risky URL query values are redacted before trace validation.
