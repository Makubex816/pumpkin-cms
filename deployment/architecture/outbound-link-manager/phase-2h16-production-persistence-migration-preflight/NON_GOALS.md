# Non-Goals

Not approved and not performed:

- implementation
- database migration
- schema migration execution
- production persistence writes
- live provider writes
- CMS writes
- MediaAsset writes
- Azure mutation
- Cosmos writes
- Cloudflare mutation
- DNS changes
- deployment
- Search Console/indexing
- external link crawling
- live HTTP checks of outbound links
- protected config reads
- secret access
- Electron implementation
- live-page publication
- repo cleanup/remediation

Any future phase that crosses one of these boundaries must receive explicit approval.
