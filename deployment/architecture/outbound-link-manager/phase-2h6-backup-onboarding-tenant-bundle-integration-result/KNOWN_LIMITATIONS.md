# Known Limitations

Phase 2H-6 is a local export and validation integration layer.

Limitations:

- local fixture/store/render outputs only;
- no live Backup Center workflow changes;
- no live onboarding import execution;
- no production tenant bundle publication;
- no live restore execution;
- no Admin UI/API;
- no database-backed persistence;
- no external link health checks;
- validators are local contract validators, not provider-runtime validators.
