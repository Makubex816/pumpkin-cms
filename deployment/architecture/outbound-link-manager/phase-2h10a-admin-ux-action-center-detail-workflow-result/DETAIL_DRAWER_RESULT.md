# Detail Drawer Result

Added a right-side read-only detail drawer on the dashboard.

The drawer shows:

- full URL
- domain
- status
- severity
- owner
- policy explanation
- policy rule reference
- render action
- risk reason
- source content
- instance locations
- scan history
- audit history
- future-gated Approve, Block, Ignore, Disable, and Enable buttons

The drawer does not mutate or call live APIs.
