# Implementation Scope

Phase 2H-2 scope is planning and QA only.

Approved outputs:

- exact package and code location recommendations;
- module boundary plan;
- schema and data contract plan;
- scanner pipeline implementation plan;
- registry and instance service plan;
- renderer, Admin, API, permission, audit, and bulk-action plan;
- Backup Center integration plan;
- onboarding and tenant bundle integration plan;
- fixture and test plan;
- phased implementation batches;
- risks and open decisions;
- next implementation prompt.

Out of scope:

- no implementation;
- no database migration;
- no schema migration execution;
- no CMS writes;
- no MediaAsset writes;
- no POST/PUT/PATCH/DELETE CMS/API requests;
- no external link crawling;
- no live HTTP checks of outbound links;
- no Azure, Cloudflare, DNS, or deployment mutation;
- no protected config reads;
- no Admin UI, Pumpkin API, or Electron implementation;
- no Search Console/indexing;
- no live-page publication.
