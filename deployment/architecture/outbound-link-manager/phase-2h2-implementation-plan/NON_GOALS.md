# Non-Goals

Phase 2H-2 does not:

- create a working scanner;
- create a registry writer;
- add C# models or controllers;
- add Admin pages or components;
- change the public renderer;
- add Backup Center code;
- run a migration;
- read live CMS data;
- crawl outbound URLs;
- check link health;
- write any tenant content;
- change deployment, DNS, Cloudflare, Search Console, or live pages.

Any future write behavior must be separately approved after local/offline foundations are proven.
