# Publishing Impact Result

Each action result includes `PUBLISHING_IMPACT.json`.

The impact output reports affected links, instances, pages, domains, source types, and whether a static rebuild may be needed. It is a local planning artifact and does not publish pages or trigger rendering.

Evidence examples:

- disable link: 1 link, 1 instance, 1 page
- policy update: 2 links, 2 instances
- scan-run simulation: 5 links, 5 instances
- bulk domain disable: 3 links, 3 instances
