# Production Gates Still Closed

V2.2.5 does not authorize production operation.

Still closed:

- Production database migration
- Production provider writes
- Additional OLM staging provider writes
- CMS writes
- MediaAsset writes
- External link crawling
- Azure infrastructure creation or mutation
- RBAC assignment changes
- Deployment
- Search Console/indexing
- DNS changes
- Live-page publication

Each item requires a future explicit approval with target, profile, rollback, backup, and validation gates.
