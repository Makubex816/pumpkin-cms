# Domain Review Reports

Domain review reports are written from local store and policy data.

Reports appear in:

- tenant bundle export: `outbound-links/EXTERNAL_DOMAIN_REVIEW.md`
- onboarding import output: `external-domain-review.md`

The report lists:

- domain;
- review status;
- link count;
- link statuses.

Statuses are derived from local policy and local link state. The report does not crawl external sites and does not perform live HTTP checks.
