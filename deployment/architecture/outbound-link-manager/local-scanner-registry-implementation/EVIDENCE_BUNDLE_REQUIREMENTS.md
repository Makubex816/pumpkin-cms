# Evidence Bundle Requirements

The execution package must include:

- migration dry-run manifest and validation
- apply-plan dry-run manifest and validation
- staging-simulated execution manifest and validation
- staging readback evidence
- runtime QA evidence or equivalent runtime QA evidence ID
- provider profile and provider capability report
- Resource Registry refresh candidate
- Backup Center pre-execution evidence
- rollback package or rollback record reference
- trace/audit/rollback continuity evidence
- first-write target entity counts

All generated evidence must remain under ignored `.tmp` output.
