# No-Go Conditions

Hard stops for the future first scoped staging-provider write:

- future explicit staging write approval is missing
- provider profile ID mismatch
- tenantKey/siteKey mismatch
- Backup Center evidence missing or failed
- runtime QA evidence missing or failed
- Resource Registry refresh candidate missing or failed
- rollback/readback plan missing
- protected config access required
- uncontrolled write path detected
- conflict, checksum mismatch, or readback mismatch detected
