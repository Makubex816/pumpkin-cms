# Abort Rollback Checklist

Abort before the future write if provider, tenant/site, Backup Center, runtime QA, Resource Registry, rollback, readback, or no-go evidence is missing.

After any future approved write, abort further writes on conflict, checksum mismatch, readback mismatch, protected config requirement, or unexpected provider response.

Rollback must use the approved rollback package and Backup Center plan only.
