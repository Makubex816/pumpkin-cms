# Implementation Scope

Implemented:

- Admin dashboard navigation entry for Outbound Links
- route pages under `/dashboard/outbound-links`
- read-only dashboard metrics
- local filters, sorting, pagination, and registry table
- link detail view
- link-specific and tenant-wide instance views
- policy, scan-run, audit, review queue, and export status views
- local typed fixture provider
- disabled write-action affordances
- focused local validation script
- Admin docs, result package, and root report

Not implemented:

- production API client wiring
- Admin write flows
- database migration
- production renderer integration
- external crawling or URL checks
- CMS/Azure/API mutations
