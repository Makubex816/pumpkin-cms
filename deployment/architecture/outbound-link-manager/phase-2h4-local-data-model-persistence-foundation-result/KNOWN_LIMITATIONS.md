# Known Limitations

Phase 2H-4 is a local persistence foundation, not production integration.

Limitations:

- file-backed `.tmp` persistence only;
- no database migration or provider-backed storage;
- no Admin UI/API;
- no CMS writes;
- no renderer integration;
- no external link health checks;
- no live-readonly inventory mode;
- export is local compatibility output only;
- validator is local schema and contract validation, not a full JSON Schema engine.
