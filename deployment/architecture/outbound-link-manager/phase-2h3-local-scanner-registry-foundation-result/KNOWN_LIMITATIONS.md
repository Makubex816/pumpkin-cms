# Known Limitations

Current local foundation limits:

- fixture JSON only;
- no database persistence;
- no CMS/API integration;
- no Admin UI;
- no production renderer integration;
- no Backup Center export integration yet;
- no onboarding validator integration yet;
- no live-readonly inventory mode;
- no external link crawling;
- no link health checks;
- no full JSON Schema engine;
- conservative URL extraction from declared fields and rich text strings.

These limits are intentional for the first local/offline foundation.
