# Operator Approval Worksheet

Production execution approval is not granted.

Operator must provide or approve:

- production provider profile ID
- concrete production provider type
- production provider mode for execution
- production target name
- production resource group or scope
- production account or host name
- production database or namespace
- production auth mode
- production identity/session type
- production tenantKey/siteKey confirmation
- Backup Center production evidence reference
- Resource Registry production binding reference
- readback method
- rollback method
- audit/trace plan acceptance
- explicit Phase 2H-26 production migration approval reference

Do not provide secret values in chat or committed docs.
