# Known Limitations

Phase 2H-5 is a rendering-control prototype, not production renderer integration.

Limitations:

- local fixture content only;
- local `.tmp` store and render output only;
- no live frontend rendering;
- no database-backed rendering rules;
- no Admin UI/API controls;
- no external link health checks;
- no runtime CMS publication;
- static export output is proof evidence only, not a deployable website export.
