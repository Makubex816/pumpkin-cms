# Local Audit Ledger Schema

Result: complete.

This is a local no-write schema definition for future implementation. V2.9.1 did not add runtime integration or a source validator.

Record shape:

| Field | Required | Notes |
| --- | --- | --- |
| `schemaVersion` | yes | Start with `audit-ledger.v1` |
| `auditEventId` | yes | Stable event ID |
| `eventType` | yes | Must be from `audit-event-taxonomy.md` |
| `v2Reference` | yes | Current reference |
| `laneId` | yes | Product lane |
| `tenantKey` | yes | Tenant key |
| `siteKey` | yes | Site key |
| `occurredAt` | yes | ISO timestamp |
| `correlationId` | yes | Links related records |
| `approvalReference` | yes | Prompt or approval reference |
| `jobRunId` | no | Required when event was generated by a job |
| `evidenceRefs` | yes | Array of safe paths or package refs |
| `outcome` | yes | `passed`, `failed`, `blocked`, `deferred`, `complete` |
| `summary` | yes | Short non-secret summary |
| `safetyBoundary` | yes | Closed/open flags for restricted actions |
| `redaction` | yes | `rawSecretsStored=false`, `rawPiiStored=false` |

Forbidden values:

- Raw tokens, OAuth credentials, auth headers, cookies, API keys, connection strings, storage keys, SAS URLs, private keys, or protected config values.
- Real customer/private data.
- Raw contact-form payload values.
