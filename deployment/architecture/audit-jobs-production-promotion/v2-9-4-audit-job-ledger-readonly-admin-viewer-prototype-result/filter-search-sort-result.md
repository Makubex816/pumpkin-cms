# Filter Search Sort Result

The Admin prototype includes local-only search, filter, and sort controls.

## Search

Search scans local Admin records across IDs, labels, states, evidence refs, trace refs, and tags.

## Filters

- Record kind.
- Record state.

## Sorting

- Timestamp.
- Label.
- Kind.
- State.
- Ascending/descending direction.

No live API or provider query is performed.
