# Paused Tenant No-Import Display Contract

RollerRinkRentals.com display:

- tenant lifecycle state: `paused`;
- import mode: `paused_no_import`;
- future import readiness: false;
- no-go condition: `tenant_paused_no_import`;
- resume approval: false;
- import action disabled;
- resume action disabled.

The display must use strong copy that the package is a preview-only paused record.

No future implementation may infer resume approval from package existence.
