# Loading Error Degraded State Plan

Loading:

- show read-only loading state per panel.

Error:

- show API envelope error code and message;
- show route or package id that failed;
- keep fixture fallback available.

Degraded:

- API unavailable;
- contract invalid;
- package missing;
- no-go endpoint unavailable;
- rollback endpoint unavailable.

Degraded state never enables future actions.
