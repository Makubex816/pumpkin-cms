# Future Admin Implementation Boundary Summary

V2.11.4 may implement a read-only Admin viewer if separately approved.

Allowed future implementation:

- route shell;
- fixture-backed provider;
- optional API-backed read-only provider;
- panels/detail views;
- query/filter/search/sort;
- disabled future actions;
- runtime QA.

Not allowed in V2.11.4 unless explicitly expanded:

- import execution;
- enabled mutation actions;
- tenant creation/resume;
- CMS/provider writes;
- deployment/DNS/indexing/contact/Azure operations.
