# Google Indexing Deferred Carryforward

Google/Search Console/indexing remains deferred by hard stop.

V2.11.4 did not run:

- Google Search Console action;
- sitemap submission to Google;
- URL Inspection API;
- Google Indexing API;
- indexing request;
- crawl or outbound URL check.

The API meta keeps `googleIndexingState` as `deferred_hard_stop`.
