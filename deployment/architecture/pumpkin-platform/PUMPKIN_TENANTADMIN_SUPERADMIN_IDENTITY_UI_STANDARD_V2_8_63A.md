# Pumpkin TenantAdmin and SuperAdmin identity UI standard V2.8.63A

TenantAdmin UI includes account/security, verified email change, password/session control, membership tenant switch, general/rename preflight, contact/form recipients, tenant users/access/transfer and scoped audit. SuperAdmin additionally receives global users/tenants, membership matrix, credential overrides with reasons, force sign-out/rotation, all-tenant contacts, rename resume/rollback, security audit and migration conflicts.

Every screen supplies loading, empty, error, denial, confirmation and keyboard-accessible behavior and never displays hashes, tokens, runtime keys or existing passwords. Feature-disabled state is prominent and disables controls. URL tenant values never imply access.
