# Commit instructions

The A04 commit model is exact-path only.

Commit 1:

```bash
git add -- deployment/architecture/build-atlas/pumpkin-downstream-build-atlas/
git commit -m "docs: establish canonical Pumpkin comprehensive build atlas"
```

Commit 2:

```bash
git add -- deployment/architecture/platform-closeout/cur-20-current-build-closeout-ingestion-result/runs/a04-prospective-comprehensive-build-atlas-inception/
git commit -m "docs: close out CUR-20 A04 atlas inception"
```

Do not use `git add -A`.
