# Security policy

A04 is documentation and read-only verification only.

Forbidden without new owner authority: Azure writes, restarts, deployments, slot swaps, scale changes, appsettings reads/writes, feature-flag changes, RBAC edits, keys, connection strings, SAS tokens, secret export, tenant, identity, CMS, media, form, DNS, TLS, indexing, Airstrip public runtime, payment mutations, real contact-form POSTs, CAPTCHA activations, or Authorize.Net transactions.

This package intentionally stores resource names and evidence hashes, not secret values.
