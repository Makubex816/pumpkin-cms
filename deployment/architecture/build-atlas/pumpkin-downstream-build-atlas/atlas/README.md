# Atlas directory

`atlas.json` is the machine-readable proposed bridge. `ATLAS.md` is the human summary. The capability and milestone files split frequently updated operational dimensions from the larger map.

The package Atlas must not replace the current build's live Atlas until:

1. the running phase closes;
2. the live Atlas is located and backed up;
3. schema and stable IDs are mapped;
4. both records are merged without losing history;
5. validation and package regeneration pass.

Every major milestone or completed build path must update the Atlas, evidence index, current state, resumption capsule, generated chat pack, manifest, checksums, and ZIP.
