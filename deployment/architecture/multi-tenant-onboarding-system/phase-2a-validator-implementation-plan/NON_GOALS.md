# Non-Goals

Phase 2A planning does not authorize:

- writing validator source code in this run
- adding npm scripts or package commands in this run
- creating CLI commands in this run
- creating a tenant
- importing content
- changing CMS records
- changing MediaAsset records
- creating or changing Azure resources
- changing Cloudflare or DNS
- deployment
- Function App setting changes
- email or Microsoft 365 actions
- Search Console, sitemap submission, URL Inspection, or indexing requests
- Roller work
- protected config reads
- secret printing

The future Phase 2A implementation should still remain offline and local-only unless a later phase explicitly expands scope.
