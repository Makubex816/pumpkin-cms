# Non-Technical Error Translations

| Technical issue | Plain-language message |
| --- | --- |
| JSON parse error | One of the package files has a formatting typo. |
| Route not allowlisted | The page address is not on the approved launch list. |
| Forbidden route present | A page that should stay offline is still in the package. |
| Local media path | An image is pointing to a local preview address instead of the public media address. |
| Form endpoint unverified | The contact form delivery path is not ready yet. |
| Noindex mismatch | A page is telling search engines the wrong crawl instruction. |
| Secret scan hit | A private credential may have been pasted into a file and must be removed. |
| Generated artifact found | Build output was placed where source docs should be. |
| Indexing hard stop | The site is not approved for Google submission yet. |
