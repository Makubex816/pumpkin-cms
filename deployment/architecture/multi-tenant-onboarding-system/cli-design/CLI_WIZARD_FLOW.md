# CLI Wizard Flow

1. Ask for tenant/site basics.
2. Ask for domains.
3. Ask for approved and forbidden routes.
4. Ask for form and mailbox owners.
5. Ask for media source metadata.
6. Ask for legal/privacy and analytics decisions.
7. Write intake docs.
8. Generate import package draft.
9. Run validation.
10. Produce report and next approval prompt.

The CLI should explain secrets and refuse obvious pasted secrets.
