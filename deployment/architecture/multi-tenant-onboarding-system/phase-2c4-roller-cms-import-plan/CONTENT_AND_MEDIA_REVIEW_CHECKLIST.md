# Content And Media Review Checklist

Complete before any CMS import execution approval.

## Content

- [ ] Home page title and placeholder copy are reviewed.
- [ ] Contact page title and placeholder copy are reviewed.
- [ ] Service areas page title and placeholder copy are reviewed.
- [ ] Approved routes match the owner-approved route list.
- [ ] Forbidden routes remain blocked.
- [ ] Page status remains draft/preview, not live.
- [ ] Content does not include private customer data.
- [ ] Content does not include hidden preview/admin/review payloads.

## Media

- [ ] Media reference `hero-roller-rink` is reviewed.
- [ ] Media filename is safe.
- [ ] Media alt text is reviewed.
- [ ] Media source status is placeholder or approved.
- [ ] Media domain is `media.rollerrinkrentals.com`.
- [ ] No media binary upload is part of this planning gate.
- [ ] No private media URL or tokenized URL is present.
- [ ] MediaAsset writes remain unapproved.

## Required Before Execution

- [ ] Content owner approves draft import planning.
- [ ] Media owner approves placeholder/reference import planning.
- [ ] Legal/privacy reviewer accepts content status for draft/preview import planning.

## Hard Stop

Importing draft content later does not approve live publication.
