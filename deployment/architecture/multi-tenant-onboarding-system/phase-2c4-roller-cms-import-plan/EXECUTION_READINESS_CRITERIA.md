## Required Before CMS Import Execution Approval

- Phase 2C-4 plan package reviewed.
- Exact package path confirmed.
- Validation report confirmed passed.
- Support packet reviewed.
- Operator handoff reviewed.
- Owner placeholders resolved or explicitly accepted for draft/preview import.
- Rollback owner confirmed.
- CMS import scope confirmed as draft/preview only.
- External systems excluded.
- Live-page hard stop acknowledged.

## Required Before CMS Import Execution

Execution is not ready until a separate approval names:

- tenant
- exact action
- package path
- validation report path
- support packet path
- CMS scope
- systems allowed to change
- systems explicitly excluded
- rollback owner
- rollback target
- evidence path
- live-page hard stop
