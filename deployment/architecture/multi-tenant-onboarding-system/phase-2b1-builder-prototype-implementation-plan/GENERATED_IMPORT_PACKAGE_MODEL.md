## Generation Mapping

- `manifest.json`: generated file inventory, tenant ID, site key, generator version, schema version, validation status.
- `tenant.json`: `tenant` answers, status `intake-draft`, runtime-only API key placeholder.
- `site.json`: `domains` and `builderProfile.deploymentProfile`.
- `routes.json`: normalized `routing.approvedRoutes`, `routing.forbiddenRoutes`, and route behavior.
- `pages/*.json`: one page file per `pages[]` item, keyed by slug.
- `media-assets.json`: `media[]` manifest metadata.
- `forms.json`: `form` metadata and safe non-secret references.
- `seo.json`: `seo` answers with `indexingFinalGate: true`.
- `theme.json`: basic navigation from approved pages.
- `redirects.json`: empty redirects array unless future answers model adds approved redirects.
- validator reports and support packet: generated by existing validator CLI after package generation.

## Deterministic Rules

- Sort generated files by stable package order.
- Sort pages by approved route order, not alphabetical order.
- Root route `/` maps to `pages/home.json`.
- Slugs use lower-case route/title-derived values and must remain stable.
- Media IDs and form IDs come from answers; builder may suggest IDs only when missing in a later interactive phase.
- JSON output uses two-space indentation and newline at EOF.
- Generated object keys should follow schema order for reviewability.

## Overwrite Behavior

- Default behavior: refuse to write if `--out` exists and is not empty.
- `--overwrite` can replace files only inside the resolved output folder.
- Builder must verify resolved output path is not a protected config directory, repo root, tenant source folder, or unrelated content-review folder.
- `--dry-run` should show planned file list and validation steps without writing package files.

## Invalid Package Behavior

- If generation succeeds but validation fails, keep local generated files and reports in the output folder.
- Mark command as failed.
- Write support packet if requested.
- Do not imply the package is import-ready.

## Search Console And Indexing

Generated `seo.json` keeps `indexingFinalGate: true`. No Search Console, sitemap submission, URL Inspection, or indexing request is generated or performed.
