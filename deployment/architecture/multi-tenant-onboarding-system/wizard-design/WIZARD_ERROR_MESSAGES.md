# Wizard Error Messages

Example messages:

- "This route is not on the approved list. Add it to approved routes or remove the page."
- "This looks like a secret token. Remove it from this field and store it only in the approved runtime secret location."
- "The mailbox owner is blank. Add the person responsible for checking contact form leads."
- "Search Console is blocked until final owner approval."

Messages should avoid technical stack traces for users and include operator detail in expandable sections.
