# Wizard Screen By Screen Spec

| Screen | Purpose |
| --- | --- |
| Welcome | Explain tenant, domain, DNS, staging, production, and secrets. |
| Business | Collect tenant display name, business type, owners. |
| Domains | Collect primary, `www`, media, DNS owner, cutover owner. |
| Pages | Collect approved routes, forbidden routes, page owners. |
| Content | Collect page text and claims review status. |
| Media | Collect media metadata, alt text, usage rights. |
| Forms | Collect recipient, mailbox owner, fields, consent status. |
| Deployment Profile | Select production flow and profile requirements. |
| Legal/Analytics | Record review and tracking decisions. |
| Validation | Show errors in plain language with fix links. |
| Approval | Require checkboxes and exact approval text. |
| Support Packet | Export redacted troubleshooting bundle. |
| Final Gate | Keep Search Console/indexing blocked until final approval. |
