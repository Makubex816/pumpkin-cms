# Wizard Field Definitions

Required fields:

- tenant display name
- tenant ID
- site key
- primary domain
- `www` domain
- media domain
- approved routes
- forbidden routes
- business type
- form recipient
- mailbox owner
- legal/privacy reviewer
- analytics/tracking decision
- production cutover owner
- rollback owner
- indexing owner

Secret fields should be marked runtime-only and should not reveal values after save.
