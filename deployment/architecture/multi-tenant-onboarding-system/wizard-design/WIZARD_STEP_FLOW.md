# Wizard Step Flow

1. Choose new tenant or resume tenant.
2. Enter business and domain basics.
3. Enter page/routes.
4. Add media metadata.
5. Configure contact form intake.
6. Record DNS/hosting owners.
7. Select deployment profile.
8. Review legal/privacy and analytics decisions.
9. Generate import package.
10. Validate package.
11. Request CMS preview approval.
12. Review staging readiness.
13. Request production cutover approval.
14. Complete manual owner review.
15. Hold Search Console/indexing for final approval.
