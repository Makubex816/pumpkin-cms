# Known Limitations

- This remains an offline validator only.
- The support packet does not zip files.
- The support packet does not copy raw source import files by default.
- Error explanations must be manually extended for future error codes.
- Markdown report snapshot tests are not yet added.
- Report JSON Schema validation is still deferred.
- Deployment profile environment-variable classification is still deferred.
- Extension manifest, permission, and migration validation are still deferred.
- No external HTTP checks are implemented.
- No tenant creation, CMS import, deployment, DNS, Azure, Cloudflare, email, Search Console/indexing, or Roller action is implemented.
