# Profile: existing-api-dynamic-site

Dynamic site profile for tenants served by an existing API-backed web app instead of a static export.

Expected components:

- Pumpkin CMS
- dynamic web frontend
- existing API hosting
- profile-specific media strategy
- profile-specific form strategy

Validators must still enforce approved routes, forbidden routes, public payload hygiene, sitemap/robots/canonical correctness, staging, production smoke, rollback, and indexing last.
