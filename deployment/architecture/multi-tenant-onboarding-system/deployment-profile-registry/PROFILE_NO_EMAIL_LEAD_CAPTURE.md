# Profile: no-email-lead-capture

Profile for tenants where contact forms store or validate leads without sending email.

Expected components:

- Pumpkin CMS
- selected hosting profile
- form delivery mode `no-email`
- owner-reviewed lead handling plan

Useful when email/Microsoft 365 is not ready. Indexing may proceed only if the owner accepts that no email delivery is active and form behavior is clearly presented.
