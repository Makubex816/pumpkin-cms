# Import Package Overview

An import package is a folder of JSON files that describe one tenant site.

It contains:

- tenant identity
- site/domain settings
- approved and forbidden routes
- page content
- media asset references
- forms
- SEO settings
- theme settings
- redirects
- validation report
- troubleshooting notes

The import package is not a deployment artifact. It is a validated source package for CMS import and review.
