# Owner Review Before Generation

Complete this review before any real tenant package is generated.

## Owner Understanding

- [ ] Owner understands this is a local dry run, not a launch.
- [ ] Owner understands no CMS import is approved.
- [ ] Owner understands no tenant is created.
- [ ] Owner understands no DNS, Cloudflare, Azure, deployment, email, Search Console, indexing, or external checks are approved.
- [ ] Owner understands Roller remains paused.
- [ ] Owner understands secrets and private customer data are forbidden.

## Owner Content Review

- [ ] Business name is correct.
- [ ] Domain intent is correct or marked placeholder.
- [ ] `www` preference is correct or marked undecided.
- [ ] Pages needed are correct.
- [ ] Page copy source is approved.
- [ ] Media sources are approved or marked placeholder.
- [ ] Media rights status is recorded.
- [ ] Service areas are correct.
- [ ] Public phone and email are correct, if used.

## Owner Form Review

- [ ] Contact form is needed or intentionally omitted.
- [ ] Lead recipient owner is known.
- [ ] Mailbox owner is known.
- [ ] Form oversight owner is known.
- [ ] Form fields are approved for dry-run package generation.
- [ ] No mailbox credentials were provided.

## Owner Governance Review

- [ ] Legal/privacy reviewer is known.
- [ ] Legal/privacy status is approved, pending, risk-accepted, or blocked.
- [ ] Analytics/tracking decision is recorded.
- [ ] Monitoring owner is known.
- [ ] Rollback owner is known.
- [ ] Final indexing owner is known.
- [ ] Owner understands Search Console and indexing are final hard stops.
