# Implementation Roadmap

## Phase 1: Docs and Schema Drafts

This Codex run creates the architecture/design package only.

## Phase 2: Validators

Implement schema validation, cross-file validation, route allowlist checks, public payload scans, media/form validators, artifact scans, and final hard-stop validators.

## Phase 3: CLI Wizard

Build a CLI that can initialize intake, validate packages, produce reports, and run dry-run gates without external mutations by default.

## Phase 4: Admin UI Wizard

Build a guided low-skill user interface with save/resume, role-based access, plain-language validation, support packet export, and approval gates.

## Phase 5: Extension Packs

Add reviewed, versioned, tenant-scoped extension packs with schema migrations, permission checks, tests, and rollback support.

## Phase 6: Deployment Profile Automation

Implement profile-aware automation for supported infrastructure flows while preserving approvals.

## Phase 7: Safe Automated Launches

Allow end-to-end launch orchestration only after validators, audit logs, approvals, rollback, and hard stops are mature.
