# Common User Mistakes

- Pasting passwords or API keys into chat.
- Sending screenshots that show secret tokens.
- Approving DNS changes before staging is reviewed.
- Forgetting to list old pages that should not go live.
- Uploading images without confirming permission to use them.
- Using a personal email inbox for business leads without an owner plan.
- Thinking staging is the final public website.
- Asking for Google indexing before final review.
- Forgetting to assign a rollback owner.
- Assuming `www.example.com` and `example.com` are always the same.
