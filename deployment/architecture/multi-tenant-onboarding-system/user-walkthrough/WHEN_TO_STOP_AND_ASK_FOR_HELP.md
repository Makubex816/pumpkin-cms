# When To Stop And Ask For Help

Stop and ask for help if:

- you see a password, token, API key, private key, connection string, deployment token, or login code
- you are asked to change DNS and do not know what record will change
- you are not sure whether an image is approved for public use
- you do not know which mailbox should receive contact form leads
- the site shows the wrong business name or another tenant name
- an old page, preview page, or draft page appears in review
- the form sends duplicate messages
- a validation report says `blocked`, `failed`, `secret`, or `external mutation`
- someone asks you to submit Search Console, submit a sitemap, use URL Inspection, or request indexing before final owner review
- you are asked to approve production cutover before staging was reviewed

Do not guess on these items. Write down what you saw, the page address if there is one, and the person who asked for the action.
