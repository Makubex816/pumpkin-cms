# Step 10: Search Console and Indexing Last

Search Console is a Google tool used to submit and monitor a website.

Indexing means asking search engines to crawl and list the website.

Indexing is last because search engines should not be invited until:

- the real domain works
- pages are approved
- wrong pages are gone
- legal/privacy review is accepted
- contact form oversight is ready
- monitoring and rollback owners are assigned

Do not request indexing, submit a sitemap, or use URL Inspection until the final approval says to do exactly that.
