# Step 03: Media and Images Intake

Media means images, logos, icons, videos, and downloadable files.

Provide:

- logo
- hero or main page images
- page-specific images
- image captions if needed
- short image descriptions for accessibility
- proof that the business can use the images

Images should not be pasted as random chat attachments for final production use unless the workflow asks for them. Use the approved intake folder or upload flow.

Do not paste private image URLs that contain secret query strings or access tokens.
