# Glossary

| Term | Meaning |
| --- | --- |
| tenant | One business website inside Pumpkin CMS. |
| domain | The public website address, such as `example.com`. |
| `www` domain | The website address with `www`, such as `www.example.com`. |
| DNS | Internet address settings that point a domain to a website host. |
| route | The part of a website address after the domain, such as `/contact/`. |
| media | Images, logos, video, or files used by the site. |
| contact form routing | The decision about where form submissions are sent. |
| staging | A review version before the real public launch. |
| production | The real public website. |
| cutover | The moment the real domain starts pointing to the new site. |
| rollback | A planned way to undo a change if something goes wrong. |
| sitemap | A file that lists public pages for search engines. |
| indexing | Search engines crawling and listing the website. |
| Search Console | A Google tool for submitting and monitoring search indexing. |
| secret | A password, API key, token, connection string, or private credential. |
