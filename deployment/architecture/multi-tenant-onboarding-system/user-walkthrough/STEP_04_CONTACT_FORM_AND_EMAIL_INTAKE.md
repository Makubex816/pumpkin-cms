# Step 04: Contact Form and Email Intake

Contact form routing means deciding where messages from the website form go.

Provide:

- public contact email
- mailbox that receives leads
- person who watches the mailbox
- backup person
- expected response time
- fields needed on the form
- spam or abuse concerns
- whether a test message is allowed later

Do not paste mailbox passwords, Microsoft 365 passwords, app secrets, or Graph secrets.

The system can test safe form behavior without sending real leads. Sending a real test message requires separate approval.
