# Troubleshooting for Non-Technical Users

## The website shows the wrong page

Write down the exact address you typed and what you expected to see. Send that to the operator.

## An image is missing

Write down the page name and describe which image is missing. Do not paste private image links with secret tokens.

## The form did not send

Write down the page, time, and what error you saw. Do not keep submitting the form many times.

## The domain does not work

Tell the operator whether `example.com`, `www.example.com`, or both are broken.

## Google does not show the site yet

That may be normal if final indexing approval has not happened. Search Console is the last step.
