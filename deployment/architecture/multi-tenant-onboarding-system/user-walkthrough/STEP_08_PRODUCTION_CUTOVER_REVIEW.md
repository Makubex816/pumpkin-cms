# Step 08: Production Cutover Review

Production cutover means the real domain starts showing the new website.

Before cutover, confirm:

- staging was reviewed
- rollback owner is assigned
- DNS owner is ready
- form owner is ready
- monitoring owner is ready
- old website backup or rollback path is understood
- email records are not supposed to change unless explicitly approved

After cutover, the operator should check that the live pages work and old test pages do not appear.
