# Pumpkin CMS New Website Walkthrough

This guide is for people who do not work with websites every day.

Pumpkin CMS can run more than one website. Each website is called a tenant. A tenant is one business website with its own pages, domain name, images, forms, owners, and launch checklist.

You do not need to understand code to help onboard a tenant. You need to gather the right business information and approve the site at each review step.

Never paste passwords, API keys, login codes, private links with secret tokens, Microsoft 365 passwords, Azure tokens, Cloudflare tokens, or deployment tokens into chat, docs, email, or git.

Search Console and indexing are last. That means Google is not asked to crawl the website until the site is live, reviewed, and approved.
