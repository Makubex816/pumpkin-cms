# Step 05: DNS and Hosting Intake

Hosting is where the website files run.

DNS points the domain to the host. Think of it like changing the address card for the website.

Provide:

- domain owner or registrar contact
- Cloudflare account or DNS provider name
- who can approve DNS changes
- current website host if there is one
- whether email already works on the domain
- records that must not be changed, especially email records

Do not paste DNS provider passwords, Cloudflare API tokens, or one-time login codes.

Production cutover is when the real public domain starts pointing to the new website.
