# Step 07: Staging Review

Staging is a private or temporary version of the website used for review before the real domain goes live.

In staging, check:

- page text
- images
- phone number
- email address
- form layout
- links
- spelling
- pages that should exist
- pages that should not exist

Staging is not the final public launch. It is the rehearsal.

Do not share staging links publicly unless the operator says they are safe to share.
