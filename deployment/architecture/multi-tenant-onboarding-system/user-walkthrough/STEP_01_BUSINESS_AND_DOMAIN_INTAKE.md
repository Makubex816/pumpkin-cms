# Step 01: Business and Domain Intake

A domain is the website address people type into a browser, such as `example.com`.

The `www` domain is the version with `www`, such as `www.example.com`.

DNS is the address book for the internet. It tells browsers where to find the website. You do not need to change DNS yourself unless an operator asks for an approved step.

Provide:

- official business name
- short display name for the website
- primary domain
- `www` domain if used
- media domain if images use a separate host
- business type
- related or paused sites that must not be touched
- person who owns production cutover decisions
- person who owns final indexing decisions

Do not paste domain registrar passwords or Cloudflare tokens.
