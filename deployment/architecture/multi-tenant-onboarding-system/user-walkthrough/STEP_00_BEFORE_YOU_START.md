# Step 00: Before You Start

Gather:

- business name
- main website domain
- best phone number
- best public email address
- pages you want on the site
- images or logos you are allowed to use
- who receives contact form leads
- who approves the final website

Do not gather or paste:

- passwords
- API keys
- login codes
- private cloud tokens
- credit card details
- mailbox passwords
- secret DNS or hosting tokens

If you do not know what something means, leave it blank and ask for help.
