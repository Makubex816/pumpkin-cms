# Step 02: Page and Content Intake

Pages are the screens visitors see on the website.

Most starter sites need:

- home page
- contact page
- service areas or locations page
- optional about page
- optional FAQ page

For each page, provide:

- page title
- page address, such as `/contact/`
- main text
- calls to action
- service claims
- phone and email details
- what pages should not exist

Mark old, duplicate, test, draft, or preview pages as forbidden routes so they do not go live by accident.
