# New Domain Onboarding Runbook

1. Confirm tenant is not paused.
2. Confirm related tenants that must not be touched.
3. Review intake forms.
4. Validate domain fields.
5. Confirm DNS owner.
6. Confirm email records that must not change.
7. Select deployment profile.
8. Run intake validation.
9. Create import package draft.
10. Stop for import validation and approval.

Do not change DNS during this runbook unless a later DNS gate is explicitly approved.
