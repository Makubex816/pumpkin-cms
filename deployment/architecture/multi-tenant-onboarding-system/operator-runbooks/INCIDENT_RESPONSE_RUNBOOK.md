# Incident Response Runbook

1. Identify tenant and affected domain.
2. Identify affected system: content, media, form, DNS, hosting, email, indexing.
3. Stop unrelated changes.
4. Preserve evidence without secrets.
5. Run read-only checks.
6. Notify owner and rollback owner.
7. Decide whether rollback is needed.
8. Execute rollback only with approval.
9. Validate after rollback.
10. Write incident report.
