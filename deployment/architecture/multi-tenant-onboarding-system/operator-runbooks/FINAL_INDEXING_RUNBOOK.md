# Final Indexing Runbook

1. Confirm production smoke passed.
2. Confirm owner review package signed.
3. Confirm content/legal/form/analytics/monitoring/rollback gates accepted.
4. Confirm sitemap/robots/canonical/noindex checks pass.
5. Confirm hidden public payload checks pass.
6. Request explicit final indexing approval.
7. If approved later, perform only approved Search Console actions.
8. Document sitemap submission, URL Inspection, indexing requests, and results.

Do not perform Search Console or indexing actions before final approval.
