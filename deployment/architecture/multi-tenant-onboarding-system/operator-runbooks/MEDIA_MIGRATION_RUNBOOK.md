# Media Migration Runbook

1. Validate media metadata.
2. Confirm usage rights status.
3. Confirm media domain/profile.
4. Confirm media owner and rollback owner.
5. Run local media URL scans.
6. Request media migration approval.
7. If approved later, perform profile-specific upload/update.
8. Run public media URL validation.
9. Confirm page output uses production media URLs.

Do not upload, delete, move blobs, or update MediaAsset records without approval.
