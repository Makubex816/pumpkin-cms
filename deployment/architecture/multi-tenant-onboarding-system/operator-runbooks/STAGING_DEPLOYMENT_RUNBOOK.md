# Staging Deployment Runbook

1. Confirm import/package validators pass.
2. Confirm media and form gates are ready or accepted as staging exceptions.
3. Confirm deployment profile.
4. Confirm staging owner.
5. Request staging deployment approval.
6. If approved later, deploy or publish to profile staging.
7. Smoke test approved routes.
8. Test forbidden routes.
9. Check media/form behavior.
10. Produce staging review package.

Do not deploy without explicit staging approval.
