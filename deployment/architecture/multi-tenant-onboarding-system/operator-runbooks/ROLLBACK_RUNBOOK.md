# Rollback Runbook

1. Confirm rollback approval.
2. Confirm exact rollback target.
3. Confirm systems excluded from rollback.
4. Confirm owner and escalation contact.
5. Execute the smallest approved rollback.
6. Run validation after rollback.
7. Document whether user-facing service is restored.
8. Document follow-up remediation.

Rollback should preserve unrelated tenant, email, media, and DNS records.
