# Troubleshooting Help Packet Template

Include:

- tenant display name
- site key
- affected domain and route
- validation report path
- last safe action performed
- public HTTP statuses
- public media URL statuses
- non-secret environment variable presence checks
- screenshots with secrets removed
- owner contact
- next requested help

Exclude:

- passwords
- API keys
- JWTs
- Azure tokens
- Cloudflare tokens
- Microsoft Graph secrets
- connection strings
- deployment tokens
- mailbox contents
