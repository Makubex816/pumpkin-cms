# Extension Permission Model

Permission examples:

- `cms:field:add`
- `cms:page:read`
- `cms:page:write-scoped`
- `media:read`
- `forms:read`
- `forms:delivery-adapter`
- `frontend:component:add`
- `api:endpoint:add`
- `validator:add`

Permissions are denied unless declared, reviewed, and tenant-approved.
