# SEO Sitemap Write Plan

## Current Evidence

Phase 2E-2 refreshed evidence shows the public sitemap has 3 entries and includes existing public pages: `home`, `contact`, and `roller-rink-rentals`. The local package expected pre-live/noindex-oriented posture until final gates.

## Default Action

Preserve current SEO, robots, canonical, published, and sitemap state.

## Future Write Options

No SEO/sitemap write is included in reconciliation by default. A later gate may propose exact changes to:

- page title;
- meta description;
- canonical URL;
- robots metadata;
- sitemap inclusion;
- published state.

## Required Approval

Any SEO/sitemap update requires:

- owner decision;
- exact before/after diff;
- rollback capture;
- separate SEO/sitemap approval;
- no Search Console/indexing action unless a final indexing gate separately approves it.

## Hard Stops

- Do not request indexing.
- Do not use Search Console.
- Do not deploy or publish live pages.
- Do not change sitemap inclusion as a side effect of content reconciliation.
