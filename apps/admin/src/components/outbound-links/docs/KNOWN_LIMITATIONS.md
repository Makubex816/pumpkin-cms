# Known Limitations

- The UI uses local fixture data only.
- No production API client wiring is enabled.
- No Admin UI write workflow is implemented.
- No live URL checking or external crawling is implemented.
- No database provider, migration, or production renderer integration is implemented.
- Authorization is inherited from the existing dashboard shell; Phase 2H-10 does not add new production permission enforcement in the UI.
- The review queue is computed from fixture status fields only.
