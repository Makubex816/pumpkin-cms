# Admin Components

Primary component file:

- `apps/admin/src/components/outbound-links/OutboundLinkAdmin.tsx`

Implemented component groups:

- frame, header, subnavigation, read-only banner
- dashboard metric grid
- registry filters, pagination, and table
- link detail view
- instance usage table
- policy card and domain lists
- scan-run table
- audit log timeline
- review queue
- export status panel
- disabled read-only action buttons

The component set uses local fixture data and keeps write controls disabled.
