# Media Requirements

All final images must be uploaded or selected through the Phase 8C.9 MediaAsset pipeline before CMS import unless a reviewer approves removing that media slot.

Rules:

- Use tenantId ice-rink-rentals and siteKey ice-rink-rentals.
- Use approved JPEG, PNG, or WebP assets only.
- Do not use SVG, base64 image data, random external URLs, or fake public URLs.
- Every non-decorative image needs alt text.
- MediaAsset status should be active before import.
- Archived, replaced, or deleted-pending assets must block production use.
- License and usage status must be approved before production.
